# 案件管理システム スケジュール（別紙）

本書は「案件管理システム 工数見積書」の別紙です。

## 1. 前提

- 日付はすべて **2026年**。1名体制・営業日（土日除外・祝日は考慮しない）ベースの予定です。
- **着手日は 2026年9月1日**、**納期は 2026年11月30日**です。
- 工数は見積書のとおり総計 100 人日です。**着手時点で完了していた項目は「完了」**と記載しています。
- 作業は見積書の記載順（上から順）に実施します。
- 末尾に予備期間（6人日）を設け、手戻り・最終調整に充てます。
